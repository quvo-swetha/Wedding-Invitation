# Quvo Wedding Invitation Gallery

Quvo gallery of digital wedding invitations. Designs are ranked **Classic**, **Premium**, and **Luxury**.

Live site: https://quvo-swetha.github.io/Wedding-Invitation/

## Folders

- `main/` — gallery (Classic / Premium / Luxury)
- `extra/` — each design, named by theme

Tap any card to open the live interactive demo. The site is built for phones first.
