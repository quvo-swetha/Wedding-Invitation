# Wedding Invitation Gallery

Local gallery modeled on [invitestory.in](https://www.invitestory.in/). Designs are ranked **Classic**, **Premium**, and **Luxury**. No prices are shown.

## Preview locally

From this folder:

```bash
npx --yes serve -p 8080
```

Then open `http://localhost:8080` (redirects to `main/`).

Tap any card to open the live interactive demo.

## Folders

- `main/` — gallery (Classic / Premium / Luxury)
- `extra/` — each design, named by theme
